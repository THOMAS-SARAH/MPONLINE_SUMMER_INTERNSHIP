# Console Serialization using C#

## Description
This project demonstrates JSON Serialization and Deserialization using the `System.Text.Json` library in C#.

## Features
- Create a Student object
- Serialize object to JSON
- Deserialize JSON back to Student object
- Display object details

## Technologies Used
- C#
- .NET
- System.Text.Json
